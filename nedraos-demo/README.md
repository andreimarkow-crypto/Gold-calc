# НедраOS — Public Demo

Independent no-data Streamlit demonstration in an isolated Git branch. No real licenses, clients, uploads, persistent files or personal data. This is an interface mockup for 14 services, not a production document processing system.

Run: `streamlit run nedraos-demo/app.py --server.address 0.0.0.0 --server.port 10000`

Deployed as a separate Render service from branch `nedraos-public-demo`. This branch does not change the default branch of Gold-calc or Global-stress-monitor.
